# Crop Disease Detection

A CNN-based deep learning project that detects whether a crop leaf is healthy or diseased.

## Technologies Used
- Python
- TensorFlow
- Keras
- Streamlit
- NumPy
- Matplotlib

## Accuracy
Validation Accuracy: 96.96%

## Features
- Image Upload
- Disease Detection
- Streamlit Web App

## Run Locally

pip install -r requirements.txt

streamlit run app.py
